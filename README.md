# 💬 ChatApp

A **full-stack real-time chat application** built with **React, TailwindCSS, Node.js, Express, MongoDB, and Socket.io**.  
It supports **JWT authentication**, **real-time messaging**, and a clean responsive UI.

---

## ✨ Features
- 🔑 Secure authentication (JWT + Cookies)
- 💬 Real-time messaging with **Socket.io**
- 👤 Online / Offline user status
- 📜 Chat history stored in MongoDB
- 🎨 Responsive UI built with TailwindCSS
- ⚡ Modern React (hooks, context API)

---

## 🛠️ Tech Stack

**Frontend:**
- React (Vite)
- TailwindCSS
- Axios

**Backend:**
- Node.js + Express
- MongoDB + Mongoose
- Socket.io
- JWT Authentication
